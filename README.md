# Google App Clone

This is a simple Google App clone made with Xcode and SwiftUI. I tried to recreate the Google homepage, including the search bar, Google logo, weather cards, and news section.

## Features
- Google-style homepage
- Dark mode switch
- Scrollable news section

## How I Made It
I used `VStack`, `HStack`, and `ZStack` to build the layout. I also used `ScrollView` to make the page scrollable, and `Image`, `Text`, SF Symbols, and Assets for the content.

I created separate Swift files for different views and used properties to customize the weather cards. I also used modifiers like `.padding()`, `.background()`, and `.font()` to make the design look similar to Google.
